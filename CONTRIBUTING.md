# Contributing

Thank you for improving these study notes.

## Workflow
1. Open an issue describing the topic, error, or improvement.
2. Create a focused branch.
3. Edit the relevant `.tex` file.
4. Compile it with `pdflatex` and inspect the output at normal reading zoom.
5. Update the matching PDF only if it compiles cleanly.
6. Open a pull request with a short summary, the exact files changed, and a note about how you checked the output.

## Standards
- Preserve correct SI units, mathematical assumptions, and C language semantics.
- Clearly distinguish definitions, intuition, examples, and theorems.
- Do not paste copyrighted textbook pages or restricted course material.
- Prefer official IITM references for course-specific information.
- Fix clipped diagrams and unreadably small labels before merging.
